# Claimora wiki

Claimora is a lightweight land-claiming plugin for Paper. Players protect their builds by marking a
rectangle with the Claim Wand, paid for with claim blocks earned by playing.

| Page | For |
| --- | --- |
| [Player guide](players.md) | Everyone: claiming, trusting, subclaims, menus, teleporting |
| [Server owner guide](server-owners.md) | Installing, permissions, admin commands, config, hooks |
| [Developer API](developers.md) | Plugin developers: the API and events |
| [Changelog](changelog.md) | What changed in each version |

**Quick start for players:** type `/claim` to get the wand, right-click two opposite corners, then
right-click again to claim. `/claim menu` does the rest.

**Quick start for server owners:** install Claimora and
[PacketEvents](https://modrinth.com/plugin/packetevents) on Paper 26.1.2, 26.2 or 26.3 (Java 25), start the server,
done. Give staff `claimora.admin.view` / `claimora.admin.teleport` / `claimora.admin` as needed.
